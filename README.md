# 🫐 Wild Blueberry Yield Prediction

Machine learning regression project focused on agricultural productivity analysis. **Kaggle Playground Series - Season 3, Episode 14**

### 🚀 Live Demo
Test the model here: [Blueberry Yield Prediction App](https://huggingface.co/spaces/bdaser/Blueberry)

### 📌 Problem
Predict the crop yield of wild blueberries using environmental, bee pollination, and weather-specific dynamics.

### 📊 Dataset
* 15,289 rows
* 18 columns
* Numerical features including pollinator counts and weather ranges

### ⚙️ Workflow
* Feature Engineering (Created total pollinators, species count, and quality ratios)
* Thermal stress/gap calculation
* Model comparison across multiple regression algorithms
* RMSE & R-Squared optimization
* Best model selection

### 🏆 Best Model
* **GradientBoostingRegressor**
* **R-Squared:** 0.824338
* **RMSE:** 555.700116
